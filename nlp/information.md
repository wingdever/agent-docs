# information about the world
智能描述世界的信息的数据结构的可选范式：
从而可以从描述世界到支持推理、检索、规划。

## 1
1. 实体表 entity
世界中存在且唯一存在于一片时空的具体对象实例
2. 类目表 category
符合一系列模板特征约束的实例的抽象范式描述
3. 性状表 trait
描述实体的指标维度，并关联实体 + 填写参数
最基本的性状是时空分布。
参数可以是字面量，或对各表其它元素的索引。
4. 关系表 relation
实体与实体之间有各种关系，可以定义出各种关系类型。
最基本的关系是时空分布的相对性，比如作为基本结构被包含。
就像实体到类目，是抽象了相似的性状属性，
实体间与类目间也往往可以抽象相似的关系。
5. 关联表 association
各个基本表之间构建关联，比如类目与它涵盖的性状维度
6. 别名表 alias
名称作为一种索引，可能一个对象有多个索引
7. 符号表 symbol
世界到对其描述的映射的基本元素或组合
8. 方法表 method
对象可以表现的改变自身或其他对象的性状的行为
9. 事件表 event
在一段从起始到终止的一段时间内，空间中相互关联的实体组合的变化或运动
10. 场景表 scene
只需要考虑有限的相关信息的局部场景。
在本体论中关注由哪些基本范畴构成概念、属性和规则。


分层：
    —实例层（entity/event）
    —抽象层（category/trait/relation-type/function）
    —符号层（alias/symbol）
    —关联层（association）

relation-type定义关系类型，可视为关系的本体论

可参考对象分层：
具体对象（particular）：实体、事件、关系实例、性状值实例，有时空位置；
抽象对象（abstract）：类目、性状维度、关系类型、方法模板、符号、规则；
描述对象（representation）：名称、文本、标识符、文档、符号串。

对应存在的秩序层次：
秩序-物理-化学-生物-社会-信息

信息实例通过映射关系以时空中的信号或实体的时空排列的方式存在于具体时空。

## 3
知识图谱三元组
RDF（Resource Description Framework，资源描述框架）
核心：一切陈述都是三元组
RDF 的基本单位是 主语—谓语—宾语 三元组
主语：被描述的资源，通常是 IRI（国际化资源标识符，类似全局唯一的 URL/ID）。
谓语：属性或关系，也通常是 IRI。
宾语：可以是另一个 IRI，也可以是字面量（如字符串、数字、日期）
